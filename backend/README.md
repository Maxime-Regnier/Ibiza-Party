# Backend

Le backend est développé avec Flask.

## Technologies

- Python
- Flask
- Flask-CORS
- ReportLab
- SMTP Gmail

## Fonctionnalités

- API REST
- Validation des formulaires
- Génération des billets PDF
- Envoi automatique des emails
- Sauvegarde des réservations
- Authentification administrateur

## Fichiers

- app.py
- data.json
- requirements.txt
- logo.webp

## Installation

```bash
pip install -r requirements.txt

python app.py
```

Le serveur démarre sur :

```
http://127.0.0.1:5000
```
