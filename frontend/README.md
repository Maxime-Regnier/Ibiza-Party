# Frontend

Le frontend est développé en HTML, CSS et JavaScript.

## Pages

- index.html
- login.html
- admin.html

## Fonctionnalités

- Présentation du festival
- Compte à rebours
- Line-up interactif
- Formulaire de réservation
- Interface administrateur
- Recherche des réservations

## Technologies

- HTML5
- CSS3
- JavaScript

## Communication

Le frontend communique avec le backend Flask grâce à l'API Fetch.

Exemple :

```javascript
fetch("http://127.0.0.1:5000/tickets")
```
